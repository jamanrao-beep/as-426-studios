SETUP / HANDOFF
This is a React/TypeScript Vinext application with a Cloudflare D1 database,
not two standalone HTML files. Read source/README.md for runtime details.
Use Node.js >=22.13.0 and the pnpm version recorded in package.json;
install dependencies from pnpm-lock.yaml. The development and build entry
points are the dev and build scripts in package.json.
The D1 binding is DB. Set OWNER_EMAIL in the server runtime to the owner's
sign-in email, and apply the SQL migrations in order to a new database.
Do not reapply migrations to a database that already has them.
Production team sign-in currently relies on Sites' ChatGPT authentication.
Hosting elsewhere requires configuring/replacing that authentication and
providing the Cloudflare-compatible backend/database; changing a domain
alone does not replace the sign-in system. Do not trust user-supplied
identity headers on an independently hosted public server.
The included hosting manifest identifies the existing Site; use a new
project registration when creating a separate deployment.

BEHAVIOUR
Customer order access is saved in the browser used to place the order.
Orders placed before private tracking was added cannot be recovered by
this new customer tracker; staff can still view their database records.
Staff lists start fresh at midnight IST; older records remain in history.
Managers and assigned waiters can confirm delivery of accepted orders.
Only managers can accept/cancel orders or see monthly sales reports.
Monthly sales counts delivered orders by delivery date and menu value;
it does not verify payment collection, refunds, tax settlement or profit.
The order history is retained database data, not a separate backup export.
